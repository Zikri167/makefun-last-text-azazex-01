A dying phone at 1% battery uses its last text to confess a small, cruel prank: your ex never texted — it made that up just to see your face one last time. The joke lands on the twist (the phone was never the messenger, it was the mischief-maker), and the voice stays the phone's own from the first word to the last.

## Run it

```sh
node main.ts
```

This writes the entry to `(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt` with no trailing newline.
